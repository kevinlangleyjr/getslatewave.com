install:

    description: Open Settings → Appearance → Themes → Manage, search for "Slatewave", then click Install and Use.
    link: https://community.obsidian.md/themes/slatewave
  - label: Slatewave CLI
    description: Clones the theme into a known location and prints the symlink commands to wire it into your vault.
    command: slatewave install obsidian
  - label: Manual clone
    description: Clone the repo directly into your vault's themes folder.
    steps:
      - Clone `obsidian-slatewave` into `<vault>/.obsidian/themes/Slatewave`
      - Open Settings → Appearance → Themes → select Slatewave
      - Optionally enable the matching color scheme under Accent color

Slatewave for Obsidian treats your vault as a companion surface to the
editor: same palette, same accents, same temperature. Optimized for
long-form reading and writing rather than dense code.
